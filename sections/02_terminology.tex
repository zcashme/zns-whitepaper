\section{Glossary}
\label{sec:glossary}

Terms defined in the body are gathered here for reference. Each is normative where it is defined; this section restates nothing.

\begin{center}
\begin{tabularx}{\textwidth}{@{}L{0.28\textwidth}Y@{}}
\toprule
Term & Definition or defining section \\
\midrule
\zns{} (Zcash Name Service) & The protocol this document specifies; see Section~\ref{sec:motivation}. \\
Zcash name & The wallet-facing string \field{n.zcash} for a canonical name \field{n}; see Section~\ref{sec:canonical-names}. \\
Canonical name & The byte string from which a \zns{} name is built; see Section~\ref{sec:canonical-names}. \\
Name Note & An Orchard note whose memo carries one canonical \zns{} tuple and whose note commitment is derived from the same tuple; see Section~\ref{sec:name-notes}. \\
Action & One of \action{claim}, \action{update}, or \action{release}; see Section~\ref{sec:name-notes}. \\
Predecessor (\field{prev\_rcm}) & The 32-byte \(\mathsf{rcm}_\sigma\) of the accepted prior Name Note for the same name, encoded as 64 lowercase hex characters; see Section~\ref{sec:name-notes}. \\
Accepted tip & The most recently accepted Name Note for a given name at a canonical chain position; see Section~\ref{sec:history}. \\
Binding (current binding) & The Unified Address in the accepted live tip, or none while released; see Section~\ref{sec:binding}. \\
Wallet & Requests a name action and completes the authorization exchange; see Section~\ref{sec:architecture}. \\
Mint & Performs the policy checks in Section~\ref{sec:mint-responsibilities} before creating a Name Note; runs inside a TEE; see Section~\ref{sec:architecture}. \\
Resolver & Performs the scan in Section~\ref{sec:resolver-scanning} and applies the state reducer; see Section~\ref{sec:architecture}. \\
Attested Mint policy & Remote attestation binding enclave measurement, Mint authority, protocol version, network, and protected-state scheme; see Section~\ref{sec:architecture}. \\
Active protocol manifest & The deployment-selected bundle of protocol version, Zcash network, activation height, viewing key, Mint note set, and field values; see Section~\ref{sec:znsips}. \\
ZNSIP & A \zns{} Improvement Proposal, processed per Section~\ref{sec:znsips}. \\
Name Note viewing key & The published Orchard full viewing key of the Name Note account; see Section~\ref{sec:motivation}. \\
One-time passcode (OTP) & A 16-byte random value issued by the Mint to a controller receiver and returned by the wallet to authorize an \action{update} or \action{release}; see Section~\ref{sec:authorization}. \\
OTP relay memo & The Orchard shielded memo \field{ZNS:otp:<name>:<verb>:<ua>:<otp>} carrying an OTP to the controller receiver; see Section~\ref{sec:authorization}. \\
\bottomrule
\end{tabularx}
\end{center}

External terms inherited from the Zcash protocol specification \cite{zcash-protocol} or its ZIPs are not redefined here: \emph{Orchard action}, \emph{Orchard memo}, \emph{note commitment} (\field{cmx}), \emph{Unified Address}, and \emph{incoming viewing key} retain the meaning fixed by their normative sources \cite{zip224,zip316,zcash-protocol}.
